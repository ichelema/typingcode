# typingcode — output dei tool di Claude Code visibili in TypingMind

Qui stanno il proxy MCP (`src/mcp/`), l'estensione TypingMind (`src/extension/`, bundle in `dist/`), gli script (`script/`), i test con il Chrome di debug (`test/tm-inspect/`) e le memorie del progetto. Repo pubblico `ichelema/typingcode`: niente segreti né dati personali nei file tracciati.
La conoscenza sta in `memory/`: leggi il file indicato dall'indice prima di decidere; per riprendere il lavoro parti da `memory/project_stato-e-roadmap.md`. Un fatto nuovo o cambiato → un file in `memory/` più una riga nell'indice. A ogni passo significativo aggiorna lo stato e aggiungi una riga a `memory/project_diario.md`, con l'ora da `date +%H:%M`.
